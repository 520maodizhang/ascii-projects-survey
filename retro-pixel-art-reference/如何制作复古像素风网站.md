# 如何制作复古像素风（Retro Pixel Art）网站

> 基于 Kimi Careers (careers.kimi.com/about-us) 源码逆向分析整理

---

## 一、风格概述

这种风格的核心是**用现代 Web 技术复刻早期计算机图形的视觉语言**：

- 8-bit / 16-bit 时代的像素图形（CGA / EGA / VGA）
- CRT 显示器的抖动和扫描线效果
- DOS / 终端的等宽字符美学
- 像素游戏的 UI 风格（硬阴影、像素图标）
- ASCII 艺术和字符画

但不是简单"做旧"，而是用 Canvas API、GSAP、Framer Motion 等现代工具做到高完成度。

## 三、逐模块实现指南

### 3.1 像素字体

**原理**：使用专门的点阵位图字体，每个字符在低分辨率网格上设计，放大后保持像素感不模糊。

**实现**：

```css
/* 1. 声明并加载像素字体 */
@font-face {
  font-family: "Fusion Pixel 12px Mono zh_hans";
  src: url("/assets/fonts/fusion-pixel-12px-mono-zh-hans.otf") format("opentype");
  font-style: normal;
  font-weight: 400;
  font-display: swap;
}

/* 2. 全局应用 */
body {
  background: #000;
  font-family: "Fusion Pixel 12px Mono zh_hans", monospace;
  /* 关键：关闭字体平滑，保持像素硬边 */
  -webkit-font-smoothing: none;
  -moz-osx-font-smoothing: unset;
}
```

**推荐像素字体**：

| 字体名 | 特点 | 来源 |
|--------|------|------|
| Fusion Pixel 12px Mono | 支持中英文，等宽，12px 点阵 | 开源 |
| Press Start 2P | 经典 8-bit 英文字体 | Google Fonts |
| VT323 | 终端风格英文字体 | Google Fonts |
| Pixelify Sans | 现代像素风，支持多语言 | Google Fonts |

| 自制 | 用 FontForge / Bits'n'Pics 编辑点阵 | — |

**关键 CSS**：

### 3.3 像素流视频（Pixel Flow Video）

**原理**：将一段普通视频通过 Canvas 逐帧降采样 + Bayer 有序抖动，转换成低分辨率像素画播放。

**核心算法**：

```
原始视频帧 → 降采样到小画布 → 读取像素数据 → 
灰度化 → 对比度调整 → Bayer 抖动 → 灰度量化 → 
按量化级数分组 → 用 fillRect 画像素块到主画布
```

**完整实现**：

```typescript
import { useRef, useEffect, useState } from "react";

// 4x4 Bayer 矩阵（用于有序抖动）
const BAYER_MATRIX = [
  0, 32, 8, 40, 2, 34, 10, 42, 48, 16, 56, 24, 50, 18, 58, 26,
  51, 19, 59, 27, 3, 35, 11, 43, 1, 33, 9, 41, 49, 17, 57, 25,
  12, 44, 4, 36, 14, 46, 6, 38, 60, 28, 52, 20, 62, 30, 54, 22,
  // ... 完整 8x8 矩阵
].map((v) => v / 64 - 0.5);

// 配置参数
const CONFIG = {
  sample: 6,         // 降采样率：每 6px 取 1px
  speed: 2.8,        // 播放速度
  dither: 0.64,      // 抖动强度 (0-1)
  levels: 6,         // 灰度量化级数
  contrast: 1.05,    // 对比度
  bright: 0,         // 亮度偏移
  ditherMode: "bayer", // "bayer" | "noise"
};

function PixelFlowVideo({ videoSrc }: { videoSrc: string }) {
  const canvasRef = useRef<HTMLCanvasElement>(null);
  const videoRef = useRef<HTMLVideoElement>(null);
  const [ready, setReady] = useState(false);

  useEffect(() => {
    const canvas = canvasRef.current!;
    const ctx = canvas.getContext("2d", { alpha: false })!;
    const video = videoRef.current!;

    let rafId: number;
    let isPlaying = false;

    const handleCanPlay = () => {
      isPlaying = true;
      setReady(true);
      video.playbackRate = CONFIG.speed;
      video.play().catch(() => {});
      rafId = requestAnimationFrame(render);
    };

    video.addEventListener("canplaythrough", handleCanPlay, { once: true });
    video.muted = true;
    video.playsInline = true;
    video.src = videoSrc;
    video.load();

    const render = () => {
      rafId = requestAnimationFrame(render);
      if (!isPlaying) return;

      const W = canvas.width = window.innerWidth;
      const H = canvas.height = window.innerHeight;

      // 1. 降采样到小画布
      const sample = CONFIG.sample;
      const sw = Math.ceil(W / sample);
      const sh = Math.ceil(H / sample);

      const smallCanvas = document.createElement("canvas");
      smallCanvas.width = sw;
      smallCanvas.height = sh;
      const sCtx = smallCanvas.getContext("2d", { willReadFrequently: true })!;
      sCtx.drawImage(video, 0, 0, sw, sh);

      // 2. 读取像素数据
      const imgData = sCtx.getImageData(0, 0, sw, sh).data;

      // 3. 清空主画布
      ctx.fillStyle = "#000";
      ctx.fillRect(0, 0, W, H);

      // 4. 预计算灰度色阶
      const levels = CONFIG.levels;
      const colors = Array.from({ length: levels }, (_, i) => {
        const v = Math.round(255 * Math.pow(i / (levels - 1), 0.85));
        return `rgb(${v},${v},${v})`;
      });

      // 5. 按色阶分组像素（减少 fillStyle 切换次数）
      const groups: Array<[number, number][]> = Array.from({ length: levels }, () => []);

      let idx = 0;
      for (let y = 0; y < sh; y++) {
        for (let x = 0; x < sw; x++) {
          const r = imgData[idx++];
          const g = imgData[idx++];
          const b = imgData[idx++];
          idx++; // skip alpha

          // 灰度化
          let gray = (0.299 * r + 0.587 * g + 0.114 * b) / 255;

          // 对比度 & 亮度
          gray = (gray - 0.5) * CONFIG.contrast + 0.5 + CONFIG.bright;

          // Bayer 抖动
          const bayerVal = BAYER_MATRIX[(y & 7) << 3 | (x & 7)];
          gray += bayerVal * CONFIG.dither * (1 / (levels - 1));

          // 量化
          let level = Math.round(gray * (levels - 1));
          level = Math.max(0, Math.min(levels - 1, level));

          if (level > 0) {
            groups[level].push([x, y]);
          }
        }
      }

      // 6. 按色阶批量绘制像素块
      for (let i = 1; i < levels; i++) {
        const group = groups[i];
        if (group.length === 0) continue;
        ctx.fillStyle = colors[i];
        for (let j = 0; j < group.length; j++) {
          ctx.fillRect(group[j][0] * sample, group[j][1] * sample, sample, sample);
        }
      }
    };

    return () => {
      cancelAnimationFrame(rafId);
      video.removeEventListener("canplaythrough", handleCanPlay);
      video.pause();
    };
  }, [videoSrc]);

  return (
    <div style={{ position: "fixed", inset: 0, overflow: "hidden" }}>
      <video ref={videoRef} style={{ position: "fixed", left: -9999, top: -9999, width: 2, height: 2 }} />
      <canvas
        ref={canvasRef}
        style={{
          position: "fixed",
          inset: 0,
          width: "100vw",
          height: "100vh",
          imageRendering: "pixelated",
          opacity: ready ? 1 : 0,
          transition: "opacity 0.35s ease-out",
        }}
      />
    </div>
  );
}
```

**参数调优表**：

| 参数 | 效果 | 推荐值 |
|------|------|--------|
| `sample` | 越大越像素化 | 桌面 6, 手机 8 |
| `dither` | 抖动强度，越大颗粒感越强 | 0.5 - 0.7 |
| `levels` | 灰度级数，越少越复古 | 4 - 8 |
| `contrast` | 对比度 | 1.0 - 1.1 |
| `ditherMode` | `bayer` 规则网格，`noise` 随机噪点 | bayer 更复古 |

### 3.4 程序化月球（Procedural Moon）

**原理**：用 Perlin 噪声生成月球表面纹理，随机添加陨石坑，模拟光照，最后用 Bayer 抖动渲染成像素画。

**这是整个风格的核心视觉元素**，Kimi 用它呼应"月之暗面"品牌名。

#### 步骤 1：Perlin 噪声生成

```typescript
// 简化版 Value Noise（Perlin 的近亲）
function makeNoise(seed: number) {
  const rng = mulberry32(seed);
  return (width: number, height: number) => {
    const grid = new Float32Array(width * height);
    for (let i = 0; i < grid.length; i++) {
      grid[i] = rng();
    }
    return { grid, width, height };
  };
}

// 双线性插值采样
function sampleNoise(
  noise: { grid: Float32Array; width: number; height: number },
  x: number,
  y: number
): number {
  const { grid, width, height } = noise;
  const fx = (x % 1 + 1) % 1 * width;
  const fy = Math.max(0, Math.min(1, y)) * (height - 1);
  const x0 = Math.floor(fx);
  const y0 = Math.floor(fy);
  const x1 = (x0 + 1) % width;
  const y1 = Math.min(height - 1, y0 + 1);
  const tx = smoothstep(fx - x0);
  const ty = smoothstep(fy - y0);
  return (
    (grid[y0 * width + x0] * (1 - tx) + grid[y0 * width + x1] * tx) * (1 - ty) +
    (grid[y1 * width + x0] * (1 - tx) + grid[y1 * width + x1] * tx) * ty
  );
}

function smoothstep(t: number): number {
  return t * t * (3 - 2 * t);
}

// 多倍频叠加（FBM）
function fbm(
  noiseLayers: Array<{ grid: Float32Array; width: number; height: number }>,
  amplitudes: number[],
  x: number,
  y: number
): number {
  let sum = 0;
  let totalAmp = 0;
  for (let i = 0; i < noiseLayers.length; i++) {
    sum += amplitudes[i] * sampleNoise(noiseLayers[i], x, y);
    totalAmp += amplitudes[i];
  }
  return sum / totalAmp;
}
```

#### 步骤 2：生成月球纹理

```typescript
function generateMoonTexture(): { tex: Float32Array; width: number; height: number } {
  const rng = mulberry32(42);
  const noise = makeNoise(42);

  // 多层噪声（从低频到高频）
  const layers = [
    noise(8, 4),     // 大陆轮廓
    noise(16, 8),    // 中等地形
    noise(32, 16),   // 小型地形
    noise(64, 32),   // 细节
    noise(128, 64),  // 更细
    noise(256, 128), // 最细
  ];
  const amplitudes = [0.5, 0.28, 0.16, 0.1, 0.07, 0.05];

  const W = 512;
  const H = 256;
  const tex = new Float32Array(W * H);

  for (let y = 0; y < H; y++) {
    for (let x = 0; x < W; x++) {
      const u = x / W;
      const v = y / H;

      // 基础地形
      let height = fbm(layers, amplitudes, u, v);

      // 极区压暗（模拟球面）
      const poleFade = sampleNoise(layers[1], u, v);
      if (poleFade < 0.42) {
        height -= 0.06 * smoothstep((0.42 - poleFade) / 0.42);
      }

      tex[y * W + x] = Math.max(0.05, Math.min(0.95, height));
    }
  }

  // 添加随机陨石坑
  const craterRng = mulberry32(9215);
  for (let i = 0; i < 28; i++) {
    const cx = W * craterRng();
    const cy = (0.18 + 0.64 * craterRng()) * H;
    const radius = 2 + 9 * craterRng();
    const isDark = craterRng() < 0.45;  // 45% 暗坑，55% 亮坑

    for (let dy = -radius; dy <= radius; dy++) {
      for (let dx = -radius; dx <= radius; dx++) {
        const px = Math.floor(cx + dx);
        const py = Math.floor(cy + dy);
        if (px < 0 || px >= W || py < 0 || py >= H) continue;

        const dist = Math.sqrt(dx * dx + dy * dy);
        if (dist > radius) continue;

        const falloff = 1 - dist / radius;
        const idx = py * W + px;
        if (isDark) {
          tex[idx] = Math.min(0.98, tex[idx] + 0.35 * falloff);
        } else {
          tex[idx] = Math.max(0.05, tex[idx] - 0.4 * Math.pow(falloff, 0.7));
        }
      }
    }
  }

  return { tex, width: W, height: H };
}
```

#### 步骤 3：渲染月球到 Canvas

```typescript
// 10 级灰度调色板
const GRAYSCALE_PALETTE = [
  "#000000", "#171717", "#282828", "#3b3b3b", "#525252",
  "#6c6c6c", "#888888", "#a6a6a6", "#c8c8c8", "#ececec",
];

// 灰度级数到调色板索引的映射
const LEVEL_MAP: Record<number, number[]> = {
  2: [0, 9],
  3: [0, 5, 9],
  4: [0, 3, 6, 9],
  5: [0, 2, 5, 7, 9],
  6: [0, 2, 4, 6, 8, 9],
  7: [0, 2, 3, 5, 6, 8, 9],
  8: [0, 1, 3, 4, 6, 7, 8, 9],
};

function renderMoon(
  ctx: CanvasRenderingContext2D,
  canvas: HTMLCanvasElement,
  moonTex: { tex: Float32Array; width: number; height: number },
  params: {
    centerX: number;
    centerY: number;
    radiusPx: number;
    rotation: number;     // 自转角度
    sunAngle: number;     // 太阳角度（度）
    litFraction: number;  // 明暗分界线位置
    pixelSize: number;    // 像素块大小
    levels: number;       // 灰度级数
    dither: number;       // 抖动强度
    alpha: number;        // 透明度
  }
) {
  const { tex, width: texW, height: texH } = moonTex;
  const W = canvas.width;
  const H = canvas.height;

  ctx.clearRect(0, 0, W, H);
  if (params.radiusPx <= 1 || params.alpha <= 0.001) return;

  const pixelSize = Math.max(1, Math.round(params.pixelSize));
  const cols = Math.ceil(W / pixelSize);
  const rows = Math.ceil(H / pixelSize);

  // 球面坐标计算
  const cx = params.centerX / pixelSize;
  const cy = params.centerY / pixelSize;
  const r = params.radiusPx / pixelSize;

  // 光照方向
  const sunRad = params.sunAngle * Math.PI / 180;
  const lightX = Math.cos(sunRad);
  const lightY = -Math.sin(sunRad);
  const lightZ = 0.35;
  const lightLen = Math.sqrt(lightX * lightX + lightY * lightY + lightZ * lightZ);
  const lx = lightX / lightLen;
  const ly = lightY / lightLen;
  const lz = lightZ / lightLen;

  // 旋转矩阵
  const cosA = Math.cos(params.rotation);
  const sinA = Math.sin(params.rotation);

  // 按颜色分组绘制（减少 fillStyle 切换）
  const groups = new Map<string, number[]>();

  for (let row = 0; row < rows; row++) {
    for (let col = 0; col < cols; col++) {
      const dx = (col + 0.5 - cx) / r;
      const dy = (row + 0.5 - cy) / r;
      const distSq = dx * dx + dy * dy;

      if (distSq >= 1) continue; // 球外

      const dz = Math.sqrt(1 - distSq);  // 球面 Z 坐标

      // 经纬度 → 纹理坐标
      const lon = Math.atan2(dx * cosA + dz * sinA, -dx * sinA + dz * cosA);
      const lat = Math.asin(Math.max(-1, Math.min(1, dy)));
      const u = lon / (2 * Math.PI) + 0.5;
      const v = lat / Math.PI + 0.5;

      // 采样纹理
      const tx = Math.min(texW - 1, Math.floor(u * texW));
      const ty = Math.min(texH - 1, Math.floor(v * texH));
      const texVal = tex[ty * texW + tx];

      // 漫反射光照
      let dot = dx * lx + dy * ly + dz * lz;
      dot += (params.litFraction - 0.5) * 2; // 调整明暗分界

      let lightness = 0;
      if (dot <= -0.18) {
        lightness = 0;
      } else if (dot >= 0.18) {
        lightness = 0.85 * Math.min(1, (dot - 0.18) / 0.82) + 0.15;
      } else {
        lightness = 0.15 * smoothstep((dot + 0.18) / 0.36);
      }

      // 边缘暗化（模拟球面边缘）
      const edgeFade = Math.pow(1 - distSq, 0.6);
      let val = (0.24 + (texVal - 0.24) * smoothstep((lightness - 0.2) / 0.22)) * lightness;
      if (val < 0.05) val = Math.max(val, 0.04 * edgeFade);

      // Bayer 抖动
      const bayer = BAYER_4X4[(row & 3) * 4 + (col & 3)];
      val += (bayer / 16 - 0.5) * (params.dither / params.levels);

      // 量化到色阶
      const levelIdx = Math.max(0, Math.min(params.levels - 1, Math.round(val * params.levels)));
      const paletteIdx = LEVEL_MAP[params.levels][levelIdx];
      const color = GRAYSCALE_PALETTE[paletteIdx];

      if (color === "#000000") continue;

      const arr = groups.get(color) || [];
      arr.push(col * pixelSize, row * pixelSize);
      groups.set(color, arr);
    }
  }

  // 批量绘制
  ctx.globalAlpha = params.alpha;
  for (const [color, positions] of groups) {
    ctx.fillStyle = color;
    for (let i = 0; i < positions.length; i += 2) {
      ctx.fillRect(positions[i], positions[i + 1], pixelSize, pixelSize);
    }
  }
  ctx.globalAlpha = 1;
}

// 4x4 Bayer 矩阵
const BAYER_4X4 = [
  0, 8, 2, 10, 12, 4, 14, 6,
  3, 11, 1, 9, 15, 7, 13, 5,
];
```

#### 步骤 4：动画循环

```typescript
function MoonCanvas() {
  const canvasRef = useRef<HTMLCanvasElement>(null);

  useEffect(() => {
    const canvas = canvasRef.current!;
    const ctx = canvas.getContext("2d")!;
    ctx.imageSmoothingEnabled = false;

    const moonTex = generateMoonTexture();
    let rafId: number;
    let rotation = 0;
    let lastTime = performance.now();

    const animate = () => {
      rafId = requestAnimationFrame(animate);

      const now = performance.now();
      const dt = Math.min((now - lastTime) / 1000, 0.05);
      lastTime = now;

      rotation += dt * 0.18; // 自转速度

      canvas.width = window.innerWidth;
      canvas.height = window.innerHeight;

      renderMoon(ctx, canvas, moonTex, {
        centerX: window.innerWidth / 2,
        centerY: window.innerHeight / 2,
        radiusPx: Math.min(window.innerWidth, window.innerHeight) * 0.3,
        rotation,
        sunAngle: 35,
        litFraction: 0.5,
        pixelSize: 4,
        levels: 6,
        dither: 0.6,
        alpha: 1,
      });
    };

    animate();
    return () => cancelAnimationFrame(rafId);
  }, []);

  return (
    <canvas
      ref={canvasRef}
      style={{
        imageRendering: "pixelated",
        width: "100vw",
        height: "100vh",
      }}
    />
  );
}
```

### 3.5 文字乱码扰动动画（Text Scramble）

**原理**：文字出现时，每个字符先在 ASCII 字符集中随机快速跳动，然后随滚动进度逐字归位到真实字符。

```typescript
import { useRef, useEffect, useState } from "react";

const SCRAMBLE_CHARS = "ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789@#$%&*";
const SCRAMBLE_COLORS = ["rgb(255,255,255)", "rgb(150,150,150)", "rgb(80,80,80)"];

function randomChar() {
  return SCRAMBLE_CHARS[Math.floor(Math.random() * SCRAMBLE_CHARS.length)];
}

function randomColor() {
  return SCRAMBLE_COLORS[Math.floor(Math.random() * SCRAMBLE_COLORS.length)];
}

function TextScramble({
  text,
  progress,  // 0-1，滚动进度
}: {
  text: string;
  progress: number;
}) {
  const [displayChars, setDisplayChars] = useState<string[]>([]);
  const [displayColors, setDisplayColors] = useState<string[]>([]);
  const rafRef = useRef<number>(0);

  useEffect(() => {
    const animate = () => {
      rafRef.current = requestAnimationFrame(animate);

      // 根据进度决定每个字符是显示真实值还是随机跳动
      const revealCount = Math.floor(progress * text.length);
      const chars: string[] = [];
      const colors: string[] = [];

      for (let i = 0; i < text.length; i++) {
        if (i < revealCount) {
          chars[i] = text[i];
          colors[i] = "rgb(255,255,255)";
        } else {
          chars[i] = randomChar();
          colors[i] = randomColor();
        }
      }

      setDisplayChars(chars);
      setDisplayColors(colors);
    };

    animate();
    return () => cancelAnimationFrame(rafRef.current);
  }, [text, progress]);

  return (
    <span>
      {displayChars.map((char, i) => (
        <span key={i} style={{ color: displayColors[i] }}>
          {char}
        </span>
      ))}
    </span>
  );
}
```

### 3.6 打字机效果（Typewriter）

**原理**：逐字显示文本，末尾带闪烁光标。

```typescript
function Typewriter({
  text,
  active,        // 是否开始打字
  speed = 55,    // 每字毫秒
  cursor = "_",  // 光标字符
}: {
  text: string;
  active: boolean;
  speed?: number;
  cursor?: string;
}) {
  const [count, setCount] = useState(0);

  useEffect(() => {
    if (!active) return;
    const timer = setInterval(() => {
      setCount((c) => {
        if (c >= text.length) {
          clearInterval(timer);
          return c;
        }
        return c + 1;
      });
    }, speed);
    return () => clearInterval(timer);
  }, [active, text, speed]);

  return (
    <span aria-label={text}>
      <span aria-hidden="true">{text.slice(0, count)}</span>
      {cursor && count < text.length && (
        <span className="ml-1 inline-block animate-pulse text-white/70">
          {cursor}
        </span>
      )}
    </span>
  );
}
```

## 四、灰度调色板设计

复古像素风的核心是**有限的色阶**。Kimi 用了 10 级灰度：

```
#000000  ████  0%   纯黑
#171717  ████  9%
#282828  ████  16%
#3b3b3b  ████  23%
#525252  ████  32%
#6c6c6c  ████  42%
#888888  ████  53%
#a6a6a6  ████  65%
#c8c8c8  ████  78%
#ececec  ████  93%  接近白
```

**设计原则**：
- 色阶间距非线性（暗部间距小，亮部间距大），模拟 CRT 的 gamma 曲线
- 最亮色不到纯白（#ececec），最暗色是纯黑，模拟 CRT 的对比度限制
- 实际渲染时只取其中 N 级（如 6 级），通过抖动模拟中间色

**生成公式**：
```typescript
function generateGrayscalePalette(levels: number): string[] {
  return Array.from({ length: levels }, (_, i) => {
    const v = Math.round(236 * Math.pow(i / (levels - 1), 0.85));
    return `#${v.toString(16).padStart(2, "0").repeat(3)}`;
  });
}
```

## 五、Bayer 抖动矩阵

有序抖动是像素风的灵魂。Bayer 矩阵决定了抖动图案的规则性。

### 4×4 Bayer 矩阵（最常用）

```
 0  8  2 10
12  4 14  6
 3 11  1  9
15  7 13  5
```

归一化：每个值除以 16 再减 0.5，得到 [-0.5, 0.4375] 范围。

### 8×8 Bayer 矩阵（Kimi 使用，更细腻）

```typescript
const BAYER_8X8 = [
  0, 32, 8, 40, 2, 34, 10, 42,
  48, 16, 56, 24, 50, 18, 58, 26,
  12, 44, 4, 36, 14, 46, 6, 38,
  60, 28, 52, 20, 62, 30, 54, 22,
  3, 35, 11, 43, 1, 33, 9, 41,
  51, 19, 59, 27, 49, 17, 57, 25,
  15, 47, 7, 39, 13, 45, 5, 37,
  63, 31, 55, 23, 61, 29, 53, 21,
].map((v) => v / 64 - 0.5);
```

**在渲染中使用**：
```typescript
// 对每个像素，根据其位置查 Bayer 矩阵
const bayerValue = BAYER_8X8[(y & 7) * 8 + (x & 7)];
// 将抖动值加到灰度上
gray += bayerValue * ditherStrength * (1 / (levels - 1));
// 然后量化到最近的色阶
const level = Math.round(gray * (levels - 1));
```

## 七、关键注意事项

### 7.1 性能优化

| 问题 | 方案 |
|------|------|
| Canvas 逐像素绘制慢 | 按颜色分组批量 `fillRect`，减少 `fillStyle` 切换 |
| `getImageData` 慢 | 用 `willReadFrequently: true` 创建 Context |
| 视频处理帧率 | 移动端降低 `sample` 到 8，跳帧渲染 |
| 页面不可见时 | 监听 `visibilitychange`，暂停 `requestAnimationFrame` |
| 月球纹理只需生成一次 | 用 `useRef` 缓存，不要每帧重新生成 |

### 7.2 移动端适配

```typescript
const isMobile = /Android|webOS|iPhone|iPad|iPod/i.test(navigator.userAgent);

const CONFIG = {
  sample: isMobile ? 8 : 6,      // 移动端降采样更多
  speed: 2.8,
  dither: isMobile ? 0.5 : 0.64, // 移动端抖动弱一些
  levels: 6,
};
```

- 像素动画用 `aria-hidden="true"`，屏幕阅读器跳过

```html

```

## 九、从 Kimi 源码中学到的设计哲学

1. **品牌即视觉**：公司叫"月之暗面"，就真的做了一个程序化生成的像素月球——品牌名不只是文字，而是整个视觉叙事的核心

2. **限制即风格**：只用 6 级灰度 + Bayer 抖动，反而比全彩更有辨识度。限制色板、限制分辨率、限制字体，每一项限制都在强化风格

3. **复古不是做旧**：不是加个滤镜就完了，而是从底层渲染逻辑（Canvas 逐像素处理、Bayer 抖动、噪声纹理）复刻早期计算机图形的生成方式

4. **细节即态度**：连鼠标光标都做了全套像素手绘（9 种状态），这种"不放过任何细节"的执行力才是高级感的来源

5. **现代技术做复古效果**：用 GSAP、Framer Motion、Canvas 2D API 等现代工具实现复古视觉，既有像素的质感又有现代的流畅动画

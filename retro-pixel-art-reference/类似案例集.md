# 复古像素风网站案例集

> 类似 Kimi Careers (careers.kimi.com/about-us) 的复古像素艺术 / 老式计算机美学网站

---

## 一、复古 OS 模拟（最接近 Kimi 的完整度）

### 1. Windows93.net

- **网址**：https://windows93.net
- **风格**：在浏览器里完整模拟一台 Windows 93 电脑，桌面、窗口、图标全部像素风
- **技术**：纯 JS + CSS，虚拟文件系统
- **亮点**：可打开多个"程序"（Paint、Notepad、Minesweeper），甚至有 BSOD

### 2. 98.js.org

- **网址**：https://98.js.org
- **风格**：Windows 98 桌面复刻，含开始菜单、窗口拖拽、右键菜单
- **技术**：React + CSS
- **亮点**：含经典 Windows 98 图标和声音，SVG 滤镜模拟 CRT 效果

---

## 二、像素游戏引擎 / 幻想主机

### 3. PICO-8（Lexaloffle）

- **网址**：https://lexaloffle.com
- **风格**：虚构的 8-bit 游戏主机，128×128 分辨率，16 色调色板
- **亮点**：完整的代码编辑器 + 像素绘图 + 音乐编辑器 + 地图编辑器，全部内置
- **与 Kimi 的关系**：同样用有限色板 + 低分辨率定义风格，PICO-8 是这种美学的"源头"之一

### 4. Bitsy

- **网址**：https://bitsy.org
- **风格**：极简像素游戏引擎，8×8 角色，单色调色板
- **亮点**：用对话和空间叙事，很多独立开发者用它做交互式像素故事

### 5. TIC-80

- **网址**：https://tic80.com
- **风格**：另一个幻想主机，类似 PICO-8 但开源，240×136 分辨率，16 色

---

## 三、终端美学（Terminal Aesthetic）

### 6. Terminal.shop

- **网址**：https://terminal.shop
- **风格**：**卖咖啡的网站做成 SSH 终端的样子**，整个购物流程在模拟终端里完成
- **亮点**：用 `ssh terminal.shop` 真的能连上去，网页版也是完整终端 UI
- **与 Kimi 的关系**：同样用等宽字体 + 暗色背景 + 字符交互，但 terminal.shop 更极端（纯文本无图形）

### 7. Warp.dev

- **网址**：https://warp.dev
- **风格**：现代终端，保留终端的字符美学但用现代 UI 渲染
- **与 Kimi 的关系**：都用等宽字体 + 暗色主题，但 Warp 偏现代，Kimi 偏复古

---

## 四、像素艺术工具与社区

### 8. Aseprite

- **网址**：https://aseprite.org
- **风格**：最专业的像素动画编辑器，自身 UI 也是像素风
- **亮点**：支持 Bayer 抖动笔刷、调色板管理、洋葱皮动画、GIF/精灵表导出
- **与 Kimi 的关系**：Kimi 的像素光标和像素背景图很可能就是用这类工具画的

### 9. Lospec

- **网址**：https://lospec.com
- **风格**：像素艺术社区，提供大量复古调色板（1-bit、CGA、EGA、NES、PICO-8 等）
- **亮点**：像素编辑器在线版 + 调色板库 + 像素游戏目录

---

## 五、创意开发者作品集（同属"用现代技术做复古/创意效果"）

### 10. Bruno Simon

- **网址**：https://bruno-simon.com
- **风格**：**作品集做成 3D 驾驶游戏**，开小车在 3D 世界里浏览项目
- **技术**：Three.js + Rapier 物理引擎 + Howler.js 音频
- **与 Kimi 的关系**：不是像素风，但精神内核一样——**把品牌叙事变成可交互体验**，用现代 Web 技术做到游戏级完成度
- **荣誉**：Awwwards Site of the Year

### 11. Active Theory

- **网址**：https://activetheory.net
- **风格**：创意技术工作室，作品大量使用 WebGL + 像素/数字美学
- **荣誉**：多次 Awwwards 获奖

---

## 六、创意编程平台

### 12. p5.js

- **网址**：https://p5js.org
- **风格**：Processing 的 JS 版，大量示例用像素/抖动/噪声生成艺术
- **与 Kimi 的关系**：Kimi 的 Perlin 噪声月球、Bayer 抖动等技术在 p5.js 社区有大量教程

### 13. Shadertoy

- **网址**：https://shadertoy.com
- **风格**：GLSL Shader 社区，有大量 CRT/扫描线/抖动效果 shader
- **与 Kimi 的关系**：Kimi 用 Canvas 2D 做的抖动效果，在 Shadertoy 上可以用 fragment shader 做到更高效

---

## 七、像素风游戏官网

### 14. Celeste

- **网址**：https://celestegame.com
- **风格**：像素平台跳跃游戏官网，雪山顶峰像素插画

### 15. Stardew Valley

- **网址**：https://stardewvalley.net
- **风格**：农场模拟像素游戏，温暖色调的像素插画

### 16. Undertale

- **网址**：https://undertale.com
- **风格**：黑白像素 RPG，极简色板 + 字符对话框

## 风格谱系总结

```
复古程度（从高到低）

纯文本终端     像素OS模拟      幻想主机        像素游戏官网      Kimi Careers
┌─────────┐  ┌──────────┐  ┌──────────┐  ┌──────────┐  ┌──────────┐
│terminal  │  │windows93 │  │ PICO-8   │  │ Celeste  │  │ 像素月球  │
│.shop    │  │.net      │  │ TIC-80   │  │ Undertale│  │ Bayer抖动 │
│         │  │ 98.js    │  │ Bitsy    │  │ Stardew  │  │ 文字扰动  │
└─────────┘  └──────────┘  └──────────┘  └──────────┘  └──────────┘
  纯字符        全UI像素化     有限色板       像素插画      程序化像素
```

**Kimi 的独特之处**在于：它不是在做游戏或模拟老系统，而是**用像素美学做品牌叙事**——程序化生成月球呼应"月之暗面"的名字，这在上述案例中是独一无二的。其他案例要么是在做产品（Aseprite、PICO-8），要么是在做游戏（Celeste、Undertale），要么是在做炫技（Bruno Simon、Windows93），而 Kimi 是在做**企业招聘品牌站**，把这种风格用在了最意想不到的场景上。
